# Shared Assets

Reusable reference assets belong here when they are not specific to one active project.

| Folder | Use |
|---|---|
| `Reference Photos` | Photos used for shape, assembly, layout, or visual accuracy reference. |
| `STL References` | Original meshes used for measurement or reverse engineering. |
| `Hardware Dimensions` | Screw, insert, bearing, connector, wire, and other hardware dimension notes. |
| `Manufacturer Datasheets` | Vendor PDFs and datasheets for real parts. |

Do not move project-critical references here unless project notes and paths are updated.
