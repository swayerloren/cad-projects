# Machine Function

The machine is likely a hand-cranked cable wrapping/taping fixture.

The cable sits in the large central C-shaped opening. A crank drives a spur gear train. The gear train rotates a crescent ring gear around the cable path. The ring gear carries a tape arm and tape roller so tape can orbit the cable.

Fixed structure:
- base plate
- top plate
- standoffs
- gear block

Moving structure:
- crank and handle
- drive gear
- driven gears
- connecting gears
- ring gear
- tape arm
- tape roller
- retaining stops

The open C-shaped ring/frame likely allows the user to place a cable into the machine from the side.
