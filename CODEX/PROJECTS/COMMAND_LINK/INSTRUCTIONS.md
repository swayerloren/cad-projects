# COMMAND_LINK Instructions

Before editing COMMAND LINK SCAD files, always read:

1. `FACTS.md`
2. `DESIGN_DECISIONS.md`
3. `ERRORS_AND_FIXES.md`
4. `DO_AND_DONT.md`
5. `OPENSCAD_PARAMETERS.md`

## Strict Rules

- Do not make a flat hobby tray.
- Design for off-road UTV vibration and shock.
- Use reinforced mount pods, ribs, gussets, and load paths.
- Use internal-only zip tie anchors, not through-wall zip tie holes.
- Use one circular grommet hole on a short side for all wires.
- Keep mounting points outside the enclosure body.
- Keep the model compact but strong.
- Do not create unnecessary holes in exterior walls.
- Keep OpenSCAD parameterized and modular.
- Preserve PCB installation/removal access.
- Preserve solder pad access.
- Preserve screw access.
- Do not modify KiCad files unless explicitly instructed.
- Do not modify fabrication files unless explicitly instructed.
- Document major corrections in this knowledge folder.
