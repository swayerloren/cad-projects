# Good Example: Rugged Lid Relay Mounting Layout

A rugged relay lid should not be a flat cap with loose relays glued on.

Good features:

- thick top panel
- O-ring groove and locating lip
- through lid fastener holes
- lower-base insert strategy
- relay bracket insert bosses on the lid underside
- reinforcement ribs tying insert bosses into the panel
- relay placeholders in preview mode
- production mode that exports only the printable lid

If a requested single relay row does not fit, document the fit failure and use a staggered layout instead of forcing collisions into the seal path.
