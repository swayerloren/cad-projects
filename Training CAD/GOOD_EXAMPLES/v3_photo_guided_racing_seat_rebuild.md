# Good Example: V3 Photo-Guided Racing Seat Rebuild

The racing seat phone stand V3 is a better pattern than V2 because it starts from photo-visible product identity:

- bucket seat shell system
- side rail/truss base system
- roll cage tube system
- phone placeholder system
- reference/preview system

Good practices:

- document why the previous version failed
- make side-view silhouette a first-class target
- preserve shoulder harness openings in the front view
- use rails, screw tabs, and triangular webbing instead of a flat base
- use `tube_between_points()` for cage members
- render phone fit and inspect it for floating/intersection problems

Quality note: V3 is still an approximation, but it is honest about that and visibly closer to the reference photos.
