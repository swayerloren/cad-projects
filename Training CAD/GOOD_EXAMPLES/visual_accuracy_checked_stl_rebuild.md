# Good Example: Visual-Accuracy-Checked STL Rebuild

A better STL rebuild records visual and functional checks before final acceptance.

Required checks:
- base outline and thickness
- styled details and text approximations
- main silhouette
- ergonomic support surfaces
- slot/lip/cutout function
- placeholder fit
- overlay against original STL
- render from multiple views

For a phone stand, always add a phone placeholder with width, thickness, height, and angle parameters.

For a rollcage or tube frame, model deliberate hoop, leg, rail, and brace paths. Avoid random diagonal tubes that only fill space.
