# Base Insert Bosses For Service Lids

Use heat-set inserts in the lower base when the lid will be removed repeatedly.

Recommended pattern:

- Lid has screw clearance holes.
- Base has blind insert pilot holes.
- Both use the same shared coordinate function or shared position list.
- Bosses should tie into floor or wall geometry instead of floating near the rim.
- Keep insert pilot holes blind unless a through-hole is intentionally sealed.

For compact sealed enclosures, fasteners may end up inside the seal line. That is acceptable only if the leak-path strategy is explicit.
