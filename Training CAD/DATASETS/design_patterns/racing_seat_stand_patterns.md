# Design Patterns: Racing Seat Phone Stand

| Pattern | Reusable idea |
|---|---|
| Seat pan cradle | Phone sits in a shallow seat-pan slot with front lip |
| Angled backrest | Viewing angle comes from backrest recline |
| Side bolsters | Style feature that also centers the phone |
| Harness slots | Small visual cutouts that signal racing seat design |
| Truss base | Thin base can look like a chassis while spreading footprint |
| Rollcage frame | Decorative tube frame adds recognizable motorsport identity |

## Parameters To Capture

- phone width
- phone thickness
- backrest angle
- slot depth
- cable notch size
- bolster diameter
- base rail spacing
- tube diameter
