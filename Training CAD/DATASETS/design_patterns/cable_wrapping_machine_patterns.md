# Design Patterns: Cable Wrapping Machine

## Patterns Captured

| Pattern | Reusable idea |
|---|---|
| C-shaped cable access | Leave a side opening so cable can be inserted without threading from an end |
| Ring gear carrier | Use a large ring/crescent gear to move a tool around a central workpiece |
| Plate gearbox | Use top and bottom plates to constrain gear Z motion |
| Printed standoff array | Align plates with repeated posts/holes |
| Roller plus stop collar | Retain a spool with a simple washer-like stop |
| Crank-driven gear train | Convert hand rotation into controlled orbiting motion |

## Good Parameters

- cable opening diameter
- ring gear arc start/end
- ring gear tooth count
- gear bore diameter
- shaft clearance
- plate thickness
- standoff diameter and height
- top plate clearance
- roller diameter and bore
- tape arm length
