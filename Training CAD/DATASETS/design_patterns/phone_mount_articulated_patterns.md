# Design Patterns: Articulated Phone Mounts

| Pattern | Reusable idea |
|---|---|
| Back plate plus bottom shelf | Separates anti-tip support from vertical load support |
| Thin X/Z plate link | Efficient printable arm form with low material use |
| Repeated small pivot holes | Allows accessory ecosystem and adjustable positions |
| Mirrored clamp jaws | Same logic can generate left/right grippers |
| Accessory adapter plate | Same mounting hole language can support webcam/lamp attachments |
| Exploded preview | Helps verify multi-part printed assemblies before export |

## Parameters Worth Exposing

- phone width
- phone thickness
- shelf depth
- back plate height
- pivot hole diameter
- screw clearance
- arm thickness
- jaw opening
- grip tooth spacing
- accessory hole spacing
