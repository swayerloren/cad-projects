# Heat-Set Insert Boss Lesson

## When To Use It

Use heat-set insert bosses when printed plastic needs durable threaded fastener retention.

## Common Mistakes

- Boss too thin around insert.
- Insert hole guessed instead of measured.
- Boss too close to unsupported edge.
- No base pad or gussets.
- No tool access for insert installation.

## Key Parameters

- `insert_hole_diameter`
- `insert_depth`
- `boss_outer_diameter`
- `boss_height`
- `base_diameter`
- `base_height`

## Manufacturing Notes

Print test coupons for actual inserts. Adjust hole diameter in small steps. Use enough perimeters and avoid overheating the plastic during insert installation.
