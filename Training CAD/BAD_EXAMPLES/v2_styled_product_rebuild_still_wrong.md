# Bad Example: V2 Styled Product Rebuild Still Wrong

Failure pattern:

- The rebuild has named modules for the right features.
- Bounding boxes and rough part categories are represented.
- The model still looks like a generic simplified OpenSCAD object.
- The side silhouette does not match the product photos.
- Functional placeholder checks are too superficial.

The racing seat phone stand V2 failed because it still did not capture the bucket shell, side rail/truss structure, and roll cage identity strongly enough.

Correct response:

- Stop claiming refinement success.
- Create a new version.
- Write a failure review.
- Rebuild around photo-visible systems.
- Render side/front/phone-fit views before judging quality.
