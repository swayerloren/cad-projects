# COMMAND LINK PCB Carrier Case Study

COMMAND LINK demonstrated several reusable PCB carrier lessons:

- A flat carrier is not enough for off-road electronics.
- PCB facts should come from KiCad/mechanical analysis, not guesses.
- Solder-wire areas need strain relief and access.
- Grommet entry should be deliberate.
- Zip-tie features should be internal-only when sealing matters.
- Mounts should be outside the PCB cavity.
- Mount ears should be clean and reinforced.
