# Individual Wall Zip-Tie Clip Brackets

Use this pattern for compact electronics enclosures where a wire bundle runs along an inside wall.

## Layout

```text
PCB edge
-> small clearance
-> wire lane
-> individual wall clip
-> solid exterior wall
```

## Clip Structure

- Raised internal wall pad.
- Upper rounded slot.
- Lower rounded slot.
- Solid bridge between slots.
- Rounded/chamfered pad perimeter.
- No through-wall cut.

## Count

Use four clips per long side by default. Six clips per side can be an optional dense mode, but it often looks like a rack/grille and should not be default.

## Checks

- Slots fit the actual zip tie width/thickness.
- Zip tie can be threaded after PCB installation.
- Exterior wall remains solid.
- Preview helpers are excluded from production STL.
