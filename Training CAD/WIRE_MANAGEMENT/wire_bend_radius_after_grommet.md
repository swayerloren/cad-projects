# Wire Bend Radius After Grommet

## Rule

After a cable enters an enclosure, verify the first bend before declaring the wire entry usable.

Starter preview:

- use the expected bundle diameter
- use a conservative minimum radius, such as 3x bundle diameter
- show the envelope in preview mode only
- check against PCB, components, posts, floor, walls, lid, and sealing features

## COMMAND LINK Example

The COMMAND LINK enclosure previews an 8 mm wire bundle with a 24 mm bend-radius envelope. This is a visual clearance check, not a harness simulation.

Physical validation is still required because actual wire stiffness, insulation, connector strain relief, and lid removal service loops can dominate the final layout.
