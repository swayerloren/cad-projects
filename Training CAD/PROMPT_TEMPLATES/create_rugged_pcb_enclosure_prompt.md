# Create Rugged PCB Enclosure Prompt

Use this prompt when starting a PCB enclosure from confirmed board facts.

```text
Read the PCB mechanical facts first. Create a rugged lower enclosure for the PCB with reinforced standoffs, serviceable board guides, intentional wire entry, internal wire strain relief, and external mounting ears. Use load paths, ribs, gussets, and clean molded geometry. Keep dimensions parameterized and do not block PCB installation, screw access, solder pads, or connectors.
```
