# Base/Lid O-Ring Seal Interface

Lesson from COMMAND LINK.

A lid-side O-ring groove is not complete by itself. The base must provide a flat or raised sealing land for compression, and the lid/base fastener layout must be checked against the seal path.

Good pattern:

- Put the O-ring groove on the lid underside when that is easier to print and inspect.
- Add a matching raised or flat sealing land on the base rim.
- Use a shared coordinate layout for lid screw clearance holes and base insert bosses.
- Keep base insert holes blind if water/dust ingress matters.
- Document whether lid screws are inside or outside the seal line.

Remaining validation:

- Actual O-ring cross-section, compression, stretch, and durometer must be tested.
- Screw holes inside the seal line need sealing washers, thread sealant, or isolated boss geometry.
