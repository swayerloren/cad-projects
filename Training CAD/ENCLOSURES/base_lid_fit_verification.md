# Base/Lid Fit Verification

For a split enclosure, standalone base and lid renders are not enough. Create a
separate assembly check that places the production base and production lid in
the installed position.

Minimum checks:

- lid seating height
- lip-to-wall clearance
- O-ring groove to sealing-land alignment
- screw clearance holes to insert pilot alignment
- insert boss depth and access
- PCB/component clearance below the lid
- production export without preview helpers

Use exploded and cutaway views so alignment errors are visible before printing.
