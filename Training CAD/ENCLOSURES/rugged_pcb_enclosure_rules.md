# Rugged PCB Enclosure Rules

- Use confirmed PCB dimensions.
- Preserve component height clearance.
- Keep screw access serviceable.
- Use reinforced standoffs.
- Manage wires with internal strain relief.
- Avoid exterior leak paths.
- Use one deliberate wire-entry feature when sealing matters.
- Keep exterior mounts outside the PCB cavity.
- Design for vibration and shock if used in vehicles.
- Do not call a design production-ready until real grommets/cable glands, heat-set inserts, zip ties, fasteners, washers, and wire bundles have been tested.
- Use printed coupons for hardware-critical features before printing the full enclosure.
- Separate an internal carrier from a sealed enclosure; if the carrier itself must seal, define lid, gasket, and drain/condensation strategy.
