# O-Ring Groove And Sealing Land Alignment

A lid-side O-ring groove only works if the base has a matching continuous
sealing land.

Good practice:

- put groove dimensions in shared parameters
- put base land dimensions in the same shared file
- verify the groove footprint sits fully inside the base land
- show an O-ring preview in assembly, not just in the lid file
- keep screw holes either outside the seal line or treat them as sealed paths

CAD alignment does not prove waterproofing. O-ring durometer, compression,
print tolerance, and clamp load need a physical test.
