# Case Study: Command Link Grommet Inner Clearance Fix

The Command Link enclosure had a correct 16 mm wire-entry hole and an outside
grommet landing, but the inside grommet collar overlapped internal rail/ledge
geometry.

Fix:

- add an inside collar clearance diameter
- start the relief at the inside wall face
- cut inward only
- center the relief on the grommet hole
- clip the relief so it does not remove the top sealing land
- keep preview grommet hardware out of production STL

Lesson: hole diameter is only one part of grommet fit. Always check the inside
collar and the wire bend path.
