# Case Study: COMMAND LINK Cable Gland Clearance Fix

Problem:

- The enclosure had a 16 mm wire-entry hole and outside boss.
- The inside relief was only sized for a grommet flange.
- A cable gland retaining nut collided with internal wire landing and rail
  geometry.

Fix:

- Added cable-gland-specific parameters.
- Increased inside clearance to a 34 mm tool/finger envelope.
- Added a production relief notch around the fitting.
- Added preview hardware for thread, outside flange, inside nut, tool
  clearance, and wire bend.

Lesson:

For waterproof fittings, model the install operation, not just the final hole.
If the nut cannot rotate during assembly, the part is not serviceable.
