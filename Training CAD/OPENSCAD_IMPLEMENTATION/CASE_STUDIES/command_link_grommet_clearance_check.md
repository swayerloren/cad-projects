# Case Study: COMMAND LINK Grommet Clearance Check

## Problem

The COMMAND LINK lower enclosure had a 16 mm circular wire-entry hole, but the grommet hardware envelope had not been checked. The outside boss was the same size as the target 24 mm flange, leaving no radial landing margin.

## Change

- Kept the 16 mm hole.
- Enlarged the outside landing boss to 28 mm OD.
- Added 0.8 mm production chamfer cuts at the hole mouths.
- Added preview-only grommet flange, wall grip, optional cable gland nut, centerline, and wire bend envelopes.
- Documented that the 20 mm wall height is tight for a 24 mm inner flange.

## Lesson

A waterproof wire entry must be checked as hardware, not only as a hole. The preview should show both sides of the wall and the first wire bend inside the enclosure.
