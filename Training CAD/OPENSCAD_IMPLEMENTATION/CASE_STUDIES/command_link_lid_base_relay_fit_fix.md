# Case Study: COMMAND LINK Lid/Base/Relay Fit Fix

Problem:

- Lid underside relay features crossed the seal channel.
- The previous fit-check render did not prove the lid could seat.
- Relay retainer brackets had a bottom tray-like floor.

Fix:

- Added shared hard keepout parameters.
- Clipped underside lid features away from the seal band.
- Added fit-check modes for closed, cutaway, seal keepout, relay keepout, and
  underside review.
- Replaced the tray bracket with an open-bottom relay top retainer.

Lesson:

For sealed assemblies, the seal path must be treated as functional geometry.
It is not enough for the lid and base to look close in an overview render.
