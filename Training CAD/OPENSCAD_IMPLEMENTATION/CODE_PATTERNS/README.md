# Code Patterns

This folder stores small, renderable OpenSCAD implementation patterns.

These are not finished products. They are teaching examples for:

- real cut geometry
- serviceable tunnels
- parameter strategy
- coordinate mapping
- preview helpers
- boss and mount construction
- wall-integrated internal wire-retention slots

Each file should render by itself in OpenSCAD.

Current wire-retention examples:

- `real_zip_tie_tunnel_pattern.scad` - minimal floor/bridge tunnel cut.
- `serviceable_cable_tie_saddle_pattern.scad` - open-top serviceable saddle pattern.
- `wall_integrated_zip_tie_bridge_pattern.scad` - inside-wall upper/lower slot bridge with solid exterior wall.
