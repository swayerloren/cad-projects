# Contributing Rules

- Add clean reusable lessons, not messy raw notes.
- Separate good examples from bad examples.
- Use before/after reviews when learning from mistakes.
- Include source context, but avoid private or unnecessary junk.
- Keep examples parameterized and reusable.
- Mark whether a lesson applies to OpenSCAD, FreeCAD, hybrid CAD, manufacturing, or reverse engineering.
- Add JSONL examples for future retrieval/training when useful.
- Update `TRAINING_INDEX.md` after adding new material.
- Do not store secrets, tokens, private identifiers, or irrelevant raw logs.
- Prefer short, focused lessons over long transcripts.
- Keep project-specific messy working memory in `CODEX`; keep generalized reusable learning here.
- When migrating old OpenSCAD lessons, keep the original source path or project reference so history is not lost.
