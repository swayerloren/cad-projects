# FreeCAD Implementation

This folder stores reusable FreeCAD implementation knowledge.

Use it for:

- project setup
- sketch and constraint workflow
- Part Design and body organization
- FreeCAD Python macros
- STEP/STL export workflow
- imported STL/STEP reference handling
- solid-modeling decisions that should be reused across projects

Project-specific FreeCAD facts belong in `CODEX\PROJECTS\<PROJECT>`.
