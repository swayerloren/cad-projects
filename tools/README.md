# Tools

This folder stores local CAD helper scripts, Python environments, FreeCAD macros, OpenSCAD scripts, and analysis outputs.

Requested canonical path:

```text
C:\Users\LJ\CAD Projects\Tools
```

Current physical folder:

```text
C:\Users\LJ\CAD Projects\tools
```

On Windows, `Tools` and `tools` resolve to the same directory. Do not rename or move this folder silently because the existing venv and scripts use the lowercase path.
