# Shared Modules

Reusable CAD code belongs here when it is useful across multiple projects.

| Folder | Use |
|---|---|
| `OpenSCAD` | Shared `.scad` modules for bosses, ribs, mounts, enclosures, cable management, and reusable parametric geometry. |
| `FreeCAD` | Shared FreeCAD Python modules and reusable macro logic. |
| `Python` | CAD analysis, export, validation, and file-processing helpers that are not tied to one project. |

Keep project-specific code inside the project until it is stable enough to generalize.
